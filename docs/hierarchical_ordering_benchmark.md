# Hierarchical Ordering and Static Condensation Performance Benchmark

This document presents performance measurements for the CG cubic Bezier bathymetry smoother with different DOF ordering and condensation strategies.

## Configuration Options

| Option | Description |
|--------|-------------|
| Standard | Default Morton ordering, no static condensation |
| Hierarchical | DOFs ordered by (level, constrained, type, hilbert_key) |
| Static Condensation | Interior DOFs eliminated at element level (single-element only) |
| Combined | Both hierarchical ordering and static condensation |

## Important Notes

- **Static condensation is currently only supported for single-element meshes**
- For multi-element meshes, the C¹ edge constraints couple interior DOFs across elements, making constraint transformation complex
- When `use_static_condensation=true` on multi-element meshes, it automatically falls back to standard assembly

## Summary

### Multi-Element Behavior

For multi-element meshes, static condensation is automatically disabled because:
1. C¹ edge constraints involve interior DOFs from adjacent elements
2. Proper constraint transformation requires complex cross-element coupling
3. The fallback ensures correctness at the cost of the 25% DOF reduction benefit

### Recommendations

1. **Single-element meshes**: Enable `use_static_condensation=true` for ~25% DOF reduction
2. **Multi-element meshes**: Use hierarchical ordering for better cache locality
3. **Future work**: Implement proper multi-element static condensation by building edge constraints on skeleton DOFs directly
